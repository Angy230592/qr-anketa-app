SMS для входа по телефону

Сюда нужна не ссылка сайта, а ключ api_id из sms.ru. Пока поле пустое, код показывается на экране телефона — для проверки. После сохранения ключа код уйдёт только в SMS.

  1. Зарегистрируйтесь на sms.ru и пополните баланс.
  2. Откройте sms.ru/?panel=api и скопируйте «Ваш api_id».
  3. Вставьте api_id в поле ниже и нажмите «Сохранить».

Таймер сбоку на каждом вопросе. 0 — без ограничения по времени.
